# Case Study Report

## 1) Problem Statement and Objectives

### Problem Statement
Accurate and reliable binary classification in healthcare datasets is challenging when feature distributions are noisy and class balance shifts between deployment settings. Traditional single-model approaches can degrade in imbalanced scenarios.

### Objectives
1. Build a robust predictive pipeline for breast-cancer diagnostic classification.
2. Compare baseline algorithms with a proposed hybrid approach.
3. Evaluate performance on both balanced and imbalanced variants.
4. Provide clear visual and statistical evidence suitable for paper drafting and presentation.

## 2) Dataset and Preprocessing

### Dataset
- Source: `sklearn.datasets.load_breast_cancer`
- Samples: 569
- Features: 30 numeric features
- Target: benign/malignant binary label

### Preprocessing Steps
1. Numeric feature standardization.
2. Stratified train/test split.
3. Creation of a synthetic imbalanced subset by reducing one class.
4. Consistent random seed for reproducibility.

## 3) Model Selection and Development

## Baseline Models
- Logistic Regression
- Random Forest
- SVM (RBF kernel)

## Proposed Model: HybridFS-Stack (HFS-Stack)

### Architecture
1. **Feature Normalization**: StandardScaler
2. **Feature Selection**: SelectKBest using Mutual Information
3. **Ensemble Core**: LR + RF + RBF-SVM
4. **Decision Fusion**: Weighted soft-voting

### Why This Approach?
- Feature selection reduces irrelevant/noisy dimensions.
- Ensemble of linear and non-linear learners improves generalization.
- Soft-voting supports probabilistic consensus and stability.

## 4) Cross-Validation and Experimental Design

- 5-fold stratified cross-validation on training split.
- Holdout evaluation with metrics:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - ROC-AUC
- Runtime (training time in seconds) tracked for complexity comparison.

## 5) Comparative Analysis

The code exports `outputs/metrics_summary.csv` containing metrics for all models and dataset variants.

Expected analysis conclusions:
1. The proposed HFS-Stack should maintain strong F1 and ROC-AUC on balanced data.
2. On imbalanced data, HFS-Stack is expected to retain higher recall/F1 than isolated baseline models.
3. Complexity is higher than single-model baselines but acceptable for tabular medical diagnostics.

## 6) Balanced vs. Unbalanced Dataset Discussion

- Balanced setting tests overall discriminative power.
- Imbalanced setting tests sensitivity to minority representation.
- For deployment, model choice should prioritize recall/F1 stability over just accuracy.

## 8) Time and Space Complexity (High-level)

- LR training: approximately linear in samples and features.
- RF training: scales with number of trees and split operations.
- RBF-SVM training: potentially superlinear in sample size.
- HFS-Stack: sum of component model costs + feature selection overhead.

Given moderate dataset size, computational overhead remains practical.
